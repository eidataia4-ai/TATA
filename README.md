# TATA Website

موقع عربي متجاوب مع لوحة تحكم محمية وقاعدة بيانات SQLite.

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل المحلي
1. فك ضغط المشروع.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ `npm install`.
4. انسخ `.env.example` إلى `.env`.
5. أنشئ كلمة مرور مدير قوية (12 حرفًا على الأقل) وسر جلسة عشوائيًا بطول 32 حرفًا على الأقل، ثم ضعهما في `.env`.
6. نفّذ `npm start`.
7. افتح `http://localhost:3000` للموقع و`http://localhost:3000/admin` للوحة التحكم.

مثال لتوليد سر جلسة:
`node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"`

## قاعدة البيانات
يُنشأ الملف `data/tata.sqlite` تلقائيًا. احتفظ بمجلد `data` في مساحة تخزين دائمة على الاستضافة، واضبط `DATA_DIR` على مسار التخزين الدائم. لا ترفع `.env` أو قاعدة البيانات إلى GitHub.

## النشر
ارفع ملفات المشروع إلى مستودع GitHub، ثم اربط المستودع بخدمة استضافة تدعم Node.js. اضبط أمر البناء (إن طُلب) على `npm install` وأمر التشغيل على `npm start`، وأضف متغيرات البيئة:
- `NODE_ENV=production`
- `ADMIN_PASSWORD` كلمة مرور قوية وسرية
- `SESSION_SECRET` سر عشوائي طويل
- `DATA_DIR` مسار القرص الدائم الذي توفره خدمة الاستضافة

يجب أن تدعم الاستضافة HTTPS ومساحة تخزين دائمة. إذا كانت الخدمة تحذف الملفات المحلية عند إعادة التشغيل، فقاعدة SQLite المحلية لن تكون دائمة؛ استخدم قرصًا دائمًا أو قاعدة بيانات مُدارة.

## الأمان
- لا يوجد حساب مدير افتراضي.
- لا تشارك كلمة مرور المدير أو `SESSION_SECRET`.
- لوحة التحكم تستخدم جلسة HttpOnly ومحددة المدة، وتقييدًا لمحاولات تسجيل الدخول.
- خذ نسخة احتياطية من مجلد `data` قبل أي ترقية.
